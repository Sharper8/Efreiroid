=== Tester l'installation avec un Hello World!
Créer un dossier _helloworld_
Ouvrez vscode dedans (`code .` en console)

Créez un fichier _main.c_ avec ce code :
[#hello,C]
----
#include <stdio.h>
#include <stdlib.h>

int main()
{
    printf("Hello World!");
}
----

Cliquer sur la flèche _Debug_ en haut à droite
Selectionner gcc

Verifier que "Hello World!" s'affiche dans la console


=== Et maintenant avec CMake
Un Makefile est un fichier qui donne les paramètres nécessaire à la génération d'un exécutable à partir du code source (nous détaillerons ça dans la prochaine séance)
CMake permet, entre autre, de décrire un projet affin de générer automatiquemet une configuration de build (ici un Makefile) adaptée à la platforme. 

kbd:[Ctrl+Shift+p] ouvre la Command Palette
Taper ```Cmake: Quick Start```
Suivre les instructions pour configurer le projet.

Commandes importantes : 
 ```Cmake: Build``` kbd:[F7]
 ```Cmake: Debug``` kbd:[Shift+F5]
 ```Cmake: Run Without Debugging``` kbd:[Ctrl+F5]
